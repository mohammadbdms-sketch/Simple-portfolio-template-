Personal Portfolio Website

A simple, modern, and responsive personal portfolio website built with HTML, CSS, and JavaScript.

This template is designed for developers, students, and beginners who want to showcase their skills, introduce themselves, and provide ways for people to get in touch.

✨ Features

- Clean and modern design
- Responsive layout for different screen sizes
- Dark and light mode
- Personal profile section
- Skills showcase
- Social media links
- Contact section
- Smooth interactive effects

🛠️ Built With

- HTML5
- CSS3
- JavaScript

🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Customize the content, images, colors, and links to make it your own.

🎨 Customization

You can personalize the template by:

- Adding your name and personal introduction.
- Updating your profile picture.
- Changing the skills and technologies displayed.
- Replacing the social media links.
- Customizing the colors and styles in "style.css".

📌 Purpose

This project was created as a personal portfolio template and a practical demonstration of frontend web development.
